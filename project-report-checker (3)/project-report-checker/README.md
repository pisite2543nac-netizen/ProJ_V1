# ตรวจรูปเล่มโครงงานเบื้องต้น (วิทยาลัยเทคนิคนางรอง)

เว็บแอปไฟล์เดียว (`index.html`) + ฐานข้อมูล Supabase สำหรับให้นักศึกษาตรวจรูปเล่มโครงงานก่อนพิมพ์ส่งผู้ตรวจจริง

## ใช้งานบนคอมพิวเตอร์ทันที
ดับเบิลคลิก `index.html` เปิดด้วย Chrome หรือ Edge (ต้องต่ออินเทอร์เน็ต) ใช้ได้เลยโดยไม่ต้องติดตั้งอะไร
คีย์บอร์ดภาษาไทยพิมพ์ตัวเลขได้ ระบบแปลงเลขไทยเป็นเลขอารบิกให้เอง

## วิธีขึ้น GitHub Pages
1. สร้าง repo แล้วอัปโหลด `index.html` และ `.nojekyll`
2. Settings → Pages → Deploy from branch → `main` / root
3. เปิดลิงก์ที่ได้ แล้วเข้าสู่ระบบ

## การเข้าสู่ระบบ
- นักศึกษา: ชื่อผู้ใช้ = รหัสนักศึกษา, รหัสผ่านเริ่มต้น = `789456123` (เปลี่ยนได้ในระบบ)
- ครู/แอดมิน: ชื่อผู้ใช้ `pisit2000` (ดูภาพรวมทุกโครงงาน, รีเซ็ตรหัสผ่านนักศึกษา)

## สิ่งที่ตรวจ (ไฟล์ .docx)
- ชื่อไฟล์ตามตาราง 01_หน้าปก ... 10_ประวัติคณะผู้จัดทำ
- A4, ขอบซ้าย 1.5 นิ้ว, ขอบบน/ล่าง/ขวา 1 นิ้ว
- ฟอนต์ TH Sarabun, เนื้อหา 16 pt, หัวข้อบท 18 pt ตัวหนา
- ข้อความตัวอย่างค้างจากแม่แบบ (......, ชื่อคนที่ 1, 25XX, x ในสารบัญ ฯลฯ) และข้อที่ว่าง
- หัวข้อที่ต้องมีของแต่ละส่วน บทที่ 1–5 บรรณานุกรม ภาคผนวก ประวัติ
- ชื่อ/รหัสนักศึกษา/ชื่อโครงงาน ตรงกับฐานข้อมูล
- บทที่ 1 ประโยชน์ ≥ วัตถุประสงค์, บทที่ 2 งานวิจัย ≥ 5 เรื่องไม่เกิน 10 ปี, เลขตาราง/ภาพ, เลขหน้า

ไฟล์ถูกตรวจในเบราว์เซอร์ ไม่อัปโหลด เก็บเฉพาะผลตรวจใน Supabase
